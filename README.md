# Harshitha — a little piece of me

A small personal single-page website made with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a new GitHub repository.
2. Upload everything in this folder, including the `images` folder.
3. In GitHub: Settings → Pages.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`.
5. Save. GitHub will provide the public page URL.

The site is responsive and needs no backend.
